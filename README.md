📌 Project Overview
This project is an interactive Business Intelligence Dashboard developed using SQL, Excel, and Power BI to analyze sales performance, profitability, customer contribution, and budget allocation. The dashboard helps businesses identify revenue trends, top-performing products, customer behavior, and regional sales insights for data-driven decision-making.
The project focuses on transforming raw business data into meaningful visual insights and strategic recommendations.
